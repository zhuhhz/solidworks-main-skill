## Known limitations

- `UPSTREAM_GAP` remains open: on SolidWorks 2024, the external backend's
  `create_semicircular_slot` width semantics produce half the requested width.
  The existing version-bounded correction remains isolated in the
  `solidworks-main-skill` adapter. The third-party source is not modified.
- HLV-minus-HLR remains necessary because the SW2024 drawing API does not
  directly expose all required visibility semantics.
- B-Rep cylinder boundaries alone cannot prove through versus blind; the
  validator combines creation, persisted Feature Tree, and topology evidence.
- Human review of generated views remains required for final engineering intent.
- Rotated, Y-major, and blind slots are not covered by this baseline.

## Release decision

`v0.4-benchmark-004` establishes a baseline in which B001–B004 pass all defined
real-SolidWorks and pytest gates. This is validated for the defined benchmark
scope and does not claim general or industrial-grade reconstruction.
